# Doctor: forecasting and evaluation

Doctor reads observations produced by Patient and predicts future health states or images.
The packaged experiments cover Section 5.2 (seven simulated mechanisms), Section 5.3.1
(blood glucose), and Section 5.3.2 (three-modality pneumonia images).
Forecasting is a component of Doctor; this module does not implement a treatment policy.

See [forecasting/README.md](forecasting/README.md) for entry points and publication status.
This lowercase `doctor` folder is a staging copy. Copy its **contents** into the existing
GitHub `Doctor/` directory, not into `Doctor/doctor/`. Original local code was not changed.
